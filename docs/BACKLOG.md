# 백로그 — 해커톤 당일 이전에 판단할 것

## 1. 시연 질문 3번 (미이수 교육) 데이터 보강 — 보류

**현재 상태**: `〔러닝포털〕` 메일 8통에 **이수/미이수 구분과 마감일이 없어** 답이 나오지 않는다.
질문 1(견적)·2(버스)는 데이터상 완전히 성립한다.

**살리려면**: 러닝포털 메일 본문에 과정별 이수 상태와 마감일을 심고,
"학습시작 안내"(09-01) → "학습현황 안내"(09-08) 사이에 이수한 과정과 안 한 과정이 갈리게 한다.
`scripts/generate_data.py`의 `COURSES` 정의만 고치면 되고 30분이면 충분하다.

**가치**: "흩어진 자동알림 8통을 한 줄로 정리"는 공감대가 크다. 다만 질문 1·2로도 시연 3~4분은 채워진다.
